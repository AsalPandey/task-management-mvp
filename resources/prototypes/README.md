# Prototype Archive

These files are preserved only as historical UI/reference material and must never be deployed.

- They are outside Laravel's `public` directory and are excluded from `git archive` deployment packages.
- They contain no working accounts or reusable credentials.
- Their client-side authentication simulation is disabled and does not persist authentication data in browser storage.
- Do not link these files from production routes or copy them into a web document root.

The Laravel application in this repository is the only deployable application.
